# Practical Column Structure → Vision AI

Flutter **Column** = vertical stack (top → bottom).

| Flutter | Vision AI (web) |
|---------|-----------------|
| Column | `.va-column` / `flex-direction: column` |
| Text widgets | `.col-title` / `.col-subtitle` |
| Text fields | `.col-field` + full-width inputs |
| Buttons | `.col-actions` primary → secondary |

Login form uses this order: brand text → tabs → inputs → primary button → OR → Google → guest.
