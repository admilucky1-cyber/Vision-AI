# Patterns learned & applied (mobile course → Vision AI web)

| Course idea | Applied in Vision AI |
|-------------|----------------------|
| AppBar + consistent padding | `.app-header` / topbar 52px, 12px rhythm |
| Drawer navigation targets | Sidebar links min 44px height |
| Form + validation | `form-validate.js` + field-error styles |
| Column layout (text→input→button) | Existing page-shell + form-column |
| ListView spacing | `.ui-list` / `.ui-list-item` |
| GridView 2-col mobile | `.ui-grid` responsive 2→3→4 |
| Card radius 12–16 + shadow | plan/skill/boost cards |
| Fade enter | message & card fade-in |
| Clean Material-like spacing | `--ui-space: 12px` system |

No third-party course names in the product.
