# Page layout system v7.1.0

Web equivalents of Flutter-style building blocks:

| Flutter-ish | CSS / HTML |
|-------------|------------|
| AppBar | `.page-topbar` / `.pl-appbar` |
| Padding | `.pl-p-md`, `.pl-safe`, tokens `--pl-pad-*` |
| Spacer | `.pl-spacer` |
| Container | `.pl-container` / `.page-body` / `.dl-wrap` |
| Column/Row | `.pl-stack` / `.pl-row` |
| Card | `.pl-card` |

All secondary pages load `page-layout-system.css` + scrollable `page-shell`.
